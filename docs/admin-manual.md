# 매장 관리자 사용 설명서

이 문서는 매장 직원이 예약 운영 화면을 사용할 때 필요한 내용을 설명합니다. 어려운 기술 용어보다 실제 화면에서 무엇을 보고, 무엇을 누르고, 그 결과가 어떻게 되는지에 집중합니다.

## 전체 흐름

1. 관리자가 판매 일정을 만듭니다.
2. 판매 일자를 “예약 가능” 상태로 엽니다.
3. 고객이 예약합니다.
4. 방문 당일 관리자가 고객의 QR 또는 수동 코드를 확인합니다.
5. 영업이 끝나면 날짜별로 마감 처리합니다.
6. 필요한 경우 노쇼, 예약 제한, 안내 문구를 관리합니다.

## 관리자 로그인

왜 필요한가:

예약 일정, 방문 확인, 영업 마감 같은 중요한 작업은 관리자만 할 수 있어야 합니다.

어떻게 사용하는가:

관리자 로그인 화면에서 아이디와 비밀번호를 입력합니다. 로그인에 성공하면 운영 콘솔로 이동합니다.

영향:

로그인에 실패하면 다시 입력하면 됩니다. 현재 백엔드는 IP 주소만으로 관리자를 자동 차단하지 않습니다.

## 메인 화면

왜 필요한가:

오늘 처리할 일과 마감되지 않은 날짜를 한눈에 보기 위한 화면입니다.

어떻게 사용하는가:

메인 화면에서 다음 메뉴로 이동합니다.

- 방문 확인
- 일정 관리
- 예약 현황
- 예약 제한
- 문구 관리
- 오늘 영업 마감

마감되지 않은 지난 영업일이 있으면 메인 화면에 날짜별로 표시됩니다.

영향:

지난 날짜의 마감 버튼을 누르면 아직 방문 완료되지 않은 고객은 노쇼로 처리될 수 있습니다. 화면에서 한 번 더 확인한 뒤에만 마감해야 합니다.

## 일정 관리

왜 필요한가:

고객이 예약할 수 있는 날짜, 일정 이름, 상품, 재고, 1인당 구매 가능 수량, 방문 시간을 정하기 위한 기능입니다.

어떻게 사용하는가:

일정 관리 화면에서 판매 날짜와 일정 이름을 입력합니다. 같은 날짜 안에 여러 일정을 만들 수 있습니다.

예:

- 2026-07-01 1차 예약
- 2026-07-01 2차 예약
- 2026-07-01 현장 수령분 예약

상품 그룹에는 함께 제한할 상품들을 넣습니다. 각 상품에는 전체 재고와 1인당 최대 구매 개수를 입력합니다.

방문 시간을 나누어 받는 경우, 시간을 직접 추가하고 각 시간에 받을 수 있는 최대 고객 수를 입력합니다.

영향:

고객은 예약 가능한 일정만 볼 수 있습니다. 재고가 부족하거나 방문 시간이 마감되면 예약은 실패합니다.

## 같은 날짜 안 다른 일정 함께 예약

왜 필요한가:

같은 판매 날짜에 여러 일정이 있을 때, 고객이 여러 일정을 한 번에 예약해도 되는지 정하기 위한 기능입니다.

어떻게 사용하는가:

각 일정마다 “같은 날짜 안 다른 일정과 함께 예약 가능” 설정을 정합니다.

영향:

고객이 같은 날짜의 여러 일정을 함께 예약하려면 선택한 일정들이 모두 함께 예약 가능 상태여야 합니다. 하나라도 꺼져 있으면 함께 예약할 수 없습니다.

## 손님에게 숫자 보여주기 설정

왜 필요한가:

매장 상황에 따라 남은 재고 수나 방문 시간별 남은 자리 수를 고객에게 보여주고 싶지 않을 수 있습니다.

어떻게 사용하는가:

일정 생성 또는 수정 화면에서 다음 설정을 조절합니다.

- 남은 재고 숫자를 손님에게 보여주기
- 방문 시간별 남은 자리 수를 손님에게 보여주기

영향:

설정을 끄면 고객 화면에는 해당 숫자가 보이지 않습니다. 다만 실제 예약 가능 여부는 그대로 검사됩니다. 숫자를 숨겨도 재고가 없거나 자리가 없으면 예약은 실패합니다.

관리자 화면에서는 운영을 위해 실제 숫자를 계속 볼 수 있습니다.

## 일정 열기와 닫기

왜 필요한가:

일정을 만들었다고 해서 바로 고객에게 열 필요는 없습니다. 예약을 시작할 때 열고, 마감할 때 닫습니다.

어떻게 사용하는가:

판매 날짜 단위로 “예약 가능 열기” 또는 “예약 마감”을 누릅니다.

영향:

예약 가능으로 열면 고객이 해당 날짜의 일정을 볼 수 있습니다. 예약 마감으로 닫으면 고객은 더 이상 새 예약을 할 수 없습니다.

## 지난 일정 보기

왜 필요한가:

오래된 일정이 기본 목록에 계속 쌓이면 현재 운영할 일정을 찾기 어렵습니다.

어떻게 사용하는가:

일정 관리 기본 화면에는 오늘 이후 일정만 표시됩니다. 지난 일정은 “지난 일정 보기” 화면에서 따로 확인합니다.

영향:

지난 일정은 페이지처럼 나누어 불러옵니다. 필요한 만큼 “더 보기”를 눌러 확인하면 됩니다.

## 예약 현황

왜 필요한가:

예약한 고객과 상품을 날짜별로 확인하기 위한 화면입니다.

어떻게 사용하는가:

예약 현황에서 날짜나 닉네임으로 검색합니다.

확인할 수 있는 정보:

- 고객명
- 일정 이름
- 상품
- 방문 시간
- 예약 일시

영향:

고객 응대, 재고 확인, 방문 전 확인에 사용합니다. 방문 완료나 노쇼 처리된 예약은 현재 예약 목록과 구분해서 다룹니다.

## 방문 확인

왜 필요한가:

현장에 온 고객이 실제 예약자인지 확인하고, 수령 완료 상태로 바꾸기 위한 기능입니다.

어떻게 사용하는가:

고객이 보여주는 방문 확인 QR을 스캔합니다. QR 인식이 잘 안 되면 고객에게 수동 코드를 발급받아 보여 달라고 안내한 뒤, 관리자가 수동 코드를 입력합니다.

영향:

확인에 성공하면 관리자 화면에 고객 예약 정보가 표시됩니다. 관리자는 내용을 확인한 뒤 방문 완료 처리합니다.

## 최근 확인 내역

왜 필요한가:

실수로 스캔 화면으로 돌아갔거나 방금 확인한 고객 정보를 다시 봐야 할 때 사용합니다.

어떻게 사용하는가:

방문 확인 메뉴에서 최근 확인 내역을 엽니다. 한 번에 불러올 개수는 5, 10, 20, 30, 50 중에서 선택할 수 있습니다.

영향:

가장 최근 확인한 내역부터 볼 수 있습니다. 필요한 경우 이전 내역을 더 불러옵니다.

## 예약 수정과 취소

왜 필요한가:

고객이 수량이나 방문 시간을 바꾸거나 예약을 취소할 수 있어야 합니다.

어떻게 사용하는가:

고객 화면의 내 예약에서 수정 또는 취소를 진행합니다.

영향:

재고, 1인당 구매 제한, 방문 시간 자리 수가 허용되는 경우에만 수정됩니다. 취소한 예약은 다시 예약할 수 있지만, 이미 방문 완료된 예약은 다시 예약할 수 없습니다.

## 영업 마감

왜 필요한가:

하루 판매가 끝난 뒤 오지 않은 고객을 노쇼로 처리하기 위한 기능입니다.

어떻게 사용하는가:

오늘 영업 마감 또는 지난 날짜의 마감 버튼을 누릅니다. 화면에 “아직 오지 않은 고객은 노쇼 처리됩니다”라는 안내가 나오면 내용을 확인한 뒤 진행합니다.

영향:

방문 완료되지 않은 예약은 노쇼로 처리됩니다. 노쇼 횟수가 기준 이상이 되면 예약 제한 대상이 될 수 있습니다.

## 예약 제한 관리

왜 필요한가:

반복적인 노쇼나 운영상 문제가 있는 고객의 예약을 제한하기 위한 기능입니다.

어떻게 사용하는가:

예약 제한 메뉴에서 제한된 고객을 확인하거나, 필요하면 직접 추가 또는 해제합니다.

영향:

제한된 고객은 예약할 수 없습니다. 해제하면 다시 예약할 수 있습니다.

## 문구 관리

왜 필요한가:

고객에게 보여줄 안내문과 예약 동의 문구를 매장 상황에 맞게 바꾸기 위한 기능입니다.

어떻게 사용하는가:

문구 관리에서 다음 문구를 수정합니다.

- 로그인 안내문
- 예약 동의 메시지
- 차단 또는 제한 안내 메시지

영향:

저장한 문구는 고객 화면에 표시됩니다. 문구를 바꾸기 위해 새 서버 이미지를 다시 만들 필요는 없습니다.

## 개인정보 처리방침

왜 필요한가:

고객이 어떤 정보가 예약 운영에 쓰이는지 확인할 수 있어야 합니다.

어떻게 사용하는가:

고객 화면에는 개인정보 처리방침 페이지로 이동하는 링크를 둡니다.

영향:

개인정보 처리방침 문서는 별도 마크다운 파일로 제공되며, 프론트 화면에서 읽기 좋게 보여줍니다.

## 고객 문의가 들어왔을 때 확인 순서

고객명이 예약 현황에 안 보이면 예약 현황 화면을 새로고침합니다. 계속 안 보이면 백엔드가 최신 버전으로 배포되었는지 확인합니다.

고객이 예약할 수 없다고 하면 일정이 열려 있는지, 재고가 남았는지, 방문 시간 자리가 남았는지 확인합니다.

고객이 회원 탈퇴를 요청하면 고객 화면의 내 정보에서 직접 탈퇴할 수 있다고 안내합니다. 탈퇴하면 계정, 예약, 방문 확인, 노쇼, 예약 제한 기록이 삭제되며 복구할 수 없습니다.

고객이 남은 재고 숫자가 안 보인다고 하면, 해당 일정에서 숫자를 숨기도록 설정했는지 확인합니다.
