# 개인정보 처리방침

reservation.io는 예약 운영에 필요한 최소한의 정보만 사용합니다.

## 수집하는 정보

- 카카오 로그인으로 확인되는 사용자 식별값
- 사용자가 직접 입력한 닉네임
- 예약한 판매 일정, 상품, 수량, 방문 시간
- 방문 확인 여부와 노쇼 처리 여부

## 사용하는 목적

- 예약자 본인 확인
- 예약 내역 조회, 수정, 취소
- 현장 방문 확인
- 노쇼 및 예약 제한 관리

## 보관과 삭제

회원 탈퇴를 요청하면 계정 정보와 개인을 식별할 수 있는 예약, 방문 확인, 노쇼, 예약 제한 기록은 삭제됩니다. 삭제 후에는 기존 계정과 연결된 예약 내역을 복구하거나 조회할 수 없습니다.

## 문의

개인정보 처리와 관련한 문의는 매장 관리자에게 연락해 주십시오.
